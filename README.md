## 🗂️ Dataset Overview

The dataset contains **8,523 rows** and **12 columns**, each row representing the sales of a specific item at a specific outlet.

| Column | Type | Description |
|---|---|---|
| Item Identifier | Text | Unique product code (1,559 distinct products) |
| Item Type | Text | Product category (16 categories, e.g. Snack Foods, Dairy, Household) |
| Item Fat Content | Text | Fat content label (`Low Fat`, `Regular`, plus inconsistent variants `LF`, `low fat`, `reg`) |
| Item Weight | Number | Product weight (1,463 records missing) |
| Item Visibility | Number | Display prominence of the item in the store |
| Outlet Identifier | Text | Unique outlet code (10 outlets) |
| Outlet Establishment Year | Number | Year the outlet was opened (2011–2022) |
| Outlet Size | Text | Small / Medium / High |
| Outlet Location Type | Text | Tier 1 / Tier 2 / Tier 3 city |
| Outlet Type | Text | Grocery Store, Supermarket Type1/Type2/Type3 |
| Sales | Number | Revenue generated by the item at that outlet |
| Rating | Number | Outlet/item rating |

**Data quality notes handled in the model:**
- `Item Fat Content` has 5 inconsistent labels for what are really 2 categories (`Low Fat`/`LF`/`low fat` and `Regular`/`reg`) — standardized for reporting.
- `Item Weight` has ~17% missing values.

## 📏 Key Measures (DAX)

The Power BI data model defines the following core measures used throughout the dashboard:

- **Total Sales** – sum of all sales revenue
- **Avg Sales** – average sales value per record
- **No of Items** – count of items sold
- **Avg Rating** – average item/outlet rating
- A **Metrics** parameter table drives a dynamic KPI card that lets the viewer switch between measures

The report is a single, densely-laid-out executive summary page titled **"blinkit — India's Last Minute App"**, organized into three zones:

**1. Filter Panel (left)**
Slicers for **Outlet Location Type**, **Outlet Size**, and **Item Type** to filter the whole report.

**2. KPI & Category View (center)**
- KPI card block: Total Sales, Avg Sales, No of Items, Avg Rating (switchable via the Metrics slicer)
- **Fat Content** donut chart — sales split by Low Fat vs. Regular
- **Fat by Outlet** clustered bar chart — fat content sales by outlet location tier
- **Item Type** bar chart — sales by product category

**3. Outlet Analysis (right)**
- **Outlet Establishment** line chart — sales trend by the year outlets opened
- **Outlet Size** donut chart — sales split by outlet size
- **Outlet Location** funnel — sales by city tier
- **Outlet Type** pivot table — Total Sales, No of Items, Avg Sales, Avg Rating, and Item Visibility broken down by outlet type

## 🔑 Key Insights

- **Total sales:** ₹12,01,681.49 across 8,523 records, averaging ₹140.99 per sale, with an average rating of 3.97/5.
- **Outlet Type drives revenue:** Supermarket Type1 alone accounts for ~₹7.88L (66% of total sales), far ahead of Grocery Stores (₹1.52L), Supermarket Type2 (₹1.31L), and Type3 (₹1.31L).
- **Tier 3 cities lead:** Tier 3 outlets generate the highest sales (₹4.72L), followed by Tier 2 (₹3.93L) and Tier 1 (₹3.36L).
- **Medium-sized outlets outperform:** Medium outlets (₹5.08L) outsell Small (₹4.45L) and High (₹2.49L) sized outlets.
- **Low Fat items outsell Regular:** Once fat-content labels are standardized, Low Fat items generate roughly 2x the sales of Regular items.
- **Top product categories:** Fruits & Vegetables and Snack Foods are the top two revenue-generating item types, followed by Household, Frozen Foods, and Dairy.
- **2018-established outlets stand out:** Outlets opened in 2018 posted the highest sales among all establishment-year cohorts (₹2.05L), notably above the ~₹1.3L generated by most other cohorts.

## ▶️ How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   ```
2. Open `blinkit_project.pbix` in **Power BI Desktop** ([download here](https://www.microsoft.com/en-us/power-platform/products/power-bi/desktop)).
3. If prompted, update the data source path to point to `BlinkIT_Grocery_Data.xlsx` on your machine.
4. Use the left-panel slicers (Outlet Location Type, Outlet Size, Item Type) and the Metrics slicer on the KPI card to explore the data interactively.
